# Boardgame Wiki Documentation & Specifications (`boardgame_wiki_docs`)

Companion documentation, product requirements (PRD), system design specifications (SDD), rule flow diagrams, Docker Compose stack, and Behavior-Driven Development (BDD) End-to-End (E2E) test suite for [`lumenconsultancyae/Boardgame-Wiki`](https://github.com/lumenconsultancyae/Boardgame-Wiki).

## Repository Contents

- [`docs/product/prd-product-requirements.md`](./docs/product/prd-product-requirements.md): Product Requirements Document (PRD) detailing user journeys for game tracking, readable rule summaries & visual graphs, WhatsApp message sharing, and UAE boardgame event tracking.
- [`docs/technical/sdd-system-design.md`](./docs/technical/sdd-system-design.md): System Design Document (SDD) covering data models, domain architecture, rule graph schema, WhatsApp message serialization, and cross-repository topology.
- [`docs/ARCHITECTURE.md`](./docs/ARCHITECTURE.md): High-level system architecture and sample boardgame rule flowcharts & relationship graphs.
